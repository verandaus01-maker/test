**8 Categories Analyzed:**

1. **SEO Score** (0-100)
   - Missing title tags

   - Poor heading structure
   - Images without alt text

2. **Performance Score** (0-100)
   - Page load speed
   - Large file sizes
   - Too many external scripts

3. **Mobile Score** (0-100)
   - Viewport configuration
   - Responsive design
   - Mobile-friendliness

4. **Content Score** (0-100)
   - Word count
   - Content quality
   - Internal/external links

5. **Technical SEO** (0-100)
   - Structured data
   - Robots.txt
   - Canonical URLs

6. **Security Score** (0-100)
   - HTTPS/SSL
   - Security headers

7. **Social Media** (0-100)
   - Facebook presence
   - Instagram presence
   - LinkedIn profile

8. **Marketing** (0-100)
   - Call-to-action buttons
   - Lead capture forms
   - Analytics tracking
   - Contact information visibility

### 4. Pitch Opportunities

- **Website Redesign**: Score < 60
- **SEO Services**: SEO score < 70
- **Mobile Optimization**: Mobile score < 70
- **Digital Marketing**: Marketing score < 70
- **Social Media Management**: < 2 social profiles

Each opportunity comes with:
- **Title**: What service to offer
